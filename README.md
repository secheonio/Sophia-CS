# 지출품의 결재 프로그램

지출 요청을 작성하고 결재 순서에 따라 승인 또는 반려하는 웹 앱의 단계별 시연 프로젝트입니다.

## 지금 시연할 수 있는 기능

- 기안자 → 담당 기관장 확인 결재 → 교장 최종 결재 → 행정실장 지출 처리 → 지출 완료
- 기안자 부서에 따른 결재선 자동 생성
- 지출품의 목록, 상태·부서별 필터, 검색
- 반려(사유 필수), 수정 후 재상신
- 영수증 이미지 첨부(최대 5장)
- 본인 기안 또는 결재선에 포함된 품의만 열람
- 시연용 사용자 전환으로 역할별 화면 확인

규칙과 조직 구조는 [결재 규칙 및 조직 구조](./docs/workflow-rules.md)에 정리되어 있습니다.

> 현재 버전은 화면과 흐름을 확인하는 프로토타입입니다. 데이터는 브라우저 메모리에만 있으며 새로고침하면 초기 시연 데이터로 돌아갑니다. 시연 화면의 사용자 이름은 모두 가상입니다. 실제 사용자 인증, 서버·데이터베이스 저장, 파일 첨부, 알림, 권한 검증은 아직 구현되지 않았습니다. 시연용 사용자 전환은 인증이나 보안 기능이 아닙니다.

## 실행

필요한 것: Node.js 20.19+ 또는 22.12+

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(보통 `http://localhost:5173`)를 브라우저에서 여세요. 상단의 시연용 사용자를 바꿔 가며 진행합니다. 예: 한기안(기안) → 김기초(기관장) → 이교장(교장) → 박행정(행정실장, 지출 처리)

## 검증

```powershell
npm run lint
npm run build
```

## 개발 단계

1. 화면 및 사용 흐름 시연 — 완료
2. 결재 규칙·조직 구조 반영 — 현재 단계 (확인 필요 항목은 규칙 문서 참조)
3. 로그인과 역할별 접근 제어 구현 (교장이 사용자 등록·직책 지정)
4. 서버 API와 데이터베이스 연결, 변경 이력 저장
5. 영수증 첨부, 알림, 검색·보고서 구현
6. 테스트, 배포 환경 설정, 실제 사용자 검수

외부 사용자가 인터넷으로 접속하는 실제 서비스에는 배포 서버와 공유 데이터베이스가 필요합니다. 공개 배포 전에는 인증과 서버 측 권한 검증을 반드시 구현해야 합니다.
