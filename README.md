# 지출품의 결재 프로그램

한 학교 안에서 쓰는 지출품의 결재 웹 프로그램입니다.
기안자 → 담당 기관장 확인 결재 → 교장 최종 결재 → 행정실장 지출 처리 순서로 진행됩니다.

## 기능

- 이메일·비밀번호 로그인 (서버 세션, 로그인 시도 제한)
- 교장(관리자)이 사용자 추가, 소속·직책 지정, 사용 중지, 비밀번호 초기화
  - 임시 비밀번호는 추가·초기화 직후 한 번만 표시되며, 첫 로그인 때 변경해야 합니다.
- 기안, 결재선 자동 생성, 승인, 반려(사유 필수), 수정 후 재상신, 지출 처리
- 영수증·견적서 이미지 첨부 (PNG·JPG·GIF·WEBP, 최대 5장, 장당 5MB)
- 열람 제한: 본인이 기안했거나 결재선에 포함된 품의만 서버에서 조회·열람 허용
- 내 결재함, 상태·부서 필터, 검색

규칙과 조직 구조는 [결재 규칙 및 조직 구조](./docs/workflow-rules.md)를 참고하세요.

## 구성

- `src/`: React + TypeScript + Vite 화면
- `server/`: Node.js + Express API, 내장 SQLite(`node:sqlite`) 저장소
- 데이터 파일: `data/app.db` (Git에 올라가지 않음)

데이터베이스는 약 20명 규모에 맞춰 PostgreSQL 대신 Node 내장 SQLite를 사용합니다. 별도 DB 설치가 필요 없고, 이후 필요하면 PostgreSQL로 옮길 수 있습니다.

## 실행 (개발)

필요한 것: Node.js 22.5+ (개발은 24에서 확인)

```powershell
npm install
npm run create-admin -- "교장 이름" principal@school.kr   # 최초 1회, 임시 비밀번호가 한 번 출력됩니다
npm run dev:server    # API 서버 (http://127.0.0.1:3001)
npm run dev           # 화면 (http://127.0.0.1:5173, /api는 3001로 전달)
```

## 실행 (운영)

```powershell
npm run build
$env:NODE_ENV = 'production'; npm run server
```

- 운영에서는 반드시 HTTPS 뒤에서 실행하세요. 로그인 쿠키가 `secure`로 발급됩니다.
- 리버스 프록시(Nginx, 클라우드 로드밸런서 등) 뒤라면 `TRUST_PROXY=1`을 설정하세요.
- 환경 변수: `PORT`(기본 3001), `HOST`(기본 127.0.0.1), `DATABASE_FILE`(기본 `data/app.db`)
- `data/` 폴더(DB 파일)를 정기적으로 백업하세요. 비밀번호 해시와 영수증 이미지가 들어 있습니다.

## 검증

```powershell
node --test server/app.test.js   # API 권한·보안 규칙 테스트
npm run build                    # 타입 검사 + 빌드
```

## 알려진 제한

- 교장 교체: 현재 교장이 직접 실행합니다. 새 교장(신규 등록 또는 기존 사용자)에게 직책과 관리자 권한이 넘어가고, 기존 교장 계정은 사용 중지됩니다. 아직 처리되지 않은 교장 결재는 새 교장에게 이관되고, 완료된 결재는 기존 교장 이름으로 남습니다. 교장은 과거 품의를 모두 열람합니다. 결재 중인 품의가 있는 기존 사용자와 행정실장은 새 교장으로 지정할 수 없습니다.
- 초대 이메일·알림 메일은 없습니다. 관리자가 임시 비밀번호를 직접 전달합니다.
- 금액별 추가 결재, 대리 결재는 없습니다(요구사항에서 제외).
- 인터넷 공개용 호스팅·HTTPS 구성은 아직 준비되지 않았습니다.
