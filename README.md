# 지출품의 결재 프로그램

지출 요청을 작성하고 결재 순서에 따라 승인 또는 반려하는 웹 앱의 단계별 시연 프로젝트입니다.

## 지금 시연할 수 있는 기능

- 지출품의 목록, 상태별 필터, 검색
- 새 지출품의 작성 및 2단계 결재선 지정
- 결재자 시연 사용자 전환
- 순차 승인, 최종 승인, 반려
- 요청 상세와 결재 진행 상태 확인

> 현재 버전은 화면과 흐름을 확인하는 프로토타입입니다. 데이터는 브라우저 메모리에만 있으며 새로고침하면 초기 시연 데이터로 돌아갑니다. 실제 사용자 인증, 서버·데이터베이스 저장, 파일 첨부, 알림, 권한 검증은 아직 구현되지 않았습니다. 시연용 사용자 전환은 인증이나 보안 기능이 아닙니다.

## 실행

필요한 것: Node.js 20.19+ 또는 22.12+

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(보통 `http://localhost:5173`)를 브라우저에서 여세요. 승인/반려를 시연하려면 상단의 시연용 사용자를 현재 결재자로 선택하세요. 예를 들어 첫 결재자는 박서준, 다음 결재자는 최유진입니다.

## 검증

```powershell
npm run lint
npm run build
```

## 개발 단계

1. 화면 및 사용 흐름 시연 — 현재 단계
2. 사용자, 조직, 금액·계정과목, 가변 결재선 규칙 확정
3. 로그인과 역할별 접근 제어 구현
4. 서버 API와 데이터베이스 연결, 변경 이력 저장
5. 영수증 첨부, 알림, 검색·보고서 구현
6. 테스트, 배포 환경 설정, 실제 사용자 검수

외부 사용자가 인터넷으로 접속하는 실제 서비스에는 배포 서버와 공유 데이터베이스가 필요합니다. 공개 배포 전에는 인증과 서버 측 권한 검증을 반드시 구현해야 합니다.
