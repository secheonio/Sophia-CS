# 서버 종료/재시작 방법

## 1. 서버 종료

실행 중인 백엔드 서버 창에서 `Ctrl + C`를 누르면 종료됩니다.

예시:
```powershell
PS D:\Sophia_Check_System> node server/index.js
지출품의 서버: http://127.0.0.1:3002
^C
```

서버가 종료되지 않거나 포트가 점유된 상태라면, 다른 PowerShell에서 포트를 점검해 강제 종료할 수 있습니다.

### 포트 점검
```powershell
Get-NetTCPConnection -LocalPort 3002 -ErrorAction SilentlyContinue
```

### 프로세스 강제 종료
```powershell
$procId = (Get-NetTCPConnection -LocalPort 3002 -ErrorAction SilentlyContinue | Select-Object -First 1 -ExpandProperty OwningProcess)
if ($procId) { Stop-Process -Id $procId -Force }
```

예시:
```powershell
Stop-Process -Id 12345 -Force
```

주의: `PID`는 PowerShell의 내장 자동 변수라서 `$pid`처럼 이름을 쓰면 에러가 납니다. `$procId` 같은 다른 이름을 사용해야 합니다. 또한 `<PID>`처럼 꺾쇠 괄호를 그대로 넣으면 파싱 오류가 납니다.

## 2. 서버 재시작

프로젝트 루트에서 다시 실행합니다.

```powershell
cd D:\Sophia_Check_System
node server/index.js
```

필요하면 환경 변수를 직접 설정해 실행할 수도 있습니다.

```powershell
cd D:\Sophia_Check_System
$env:PORT='3002'
$env:HOST='127.0.0.1'
node server/index.js
```

정상 실행 시 출력 예시:
```text
지출품의 서버: http://127.0.0.1:3002
```

---

## 3. 프론트엔드와 백엔드 함께 재시작

백엔드와 프론트는 각각 별도 콘솔에서 실행합니다.

### 백엔드
```powershell
cd D:\Sophia_Check_System
node server/index.js
```

### 프론트엔드
```powershell
cd D:\Sophia_Check_System
npm run dev
```

기본 주소는 다음과 같습니다.

- 백엔드: http://127.0.0.1:3002
- 프론트: http://127.0.0.1:3100

---

## 4. 가장 안전한 재시작 순서

1. 현재 서버 창에서 `Ctrl + C`로 종료
2. 포트 사용 여부 확인
3. 백엔드 다시 실행
4. 필요 시 프론트엔드 다시 실행

이 순서가 가장 안전하고 에러가 적습니다.

---

## 5. 주의사항

- 명령이 붙어서 입력되면 Node가 파일 경로를 잘못 해석할 수 있습니다.
- 다음처럼 붙어서 입력하면 실패합니다.

```powershell
node server/index.js$env:PORT='3002'; $env:HOST='127.0.0.1'; node server/index.js
```

정상 문법은 아래처럼 입력해야 합니다.

```powershell
cd D:\Sophia_Check_System; $env:PORT='3002'; $env:HOST='127.0.0.1'; node server/index.js
```

또는

```powershell
cd D:\Sophia_Check_System
$env:PORT='3002'
$env:HOST='127.0.0.1'
node server/index.js
```

## 6. 한 번에 처리하는 PowerShell 스크립트

아래 스크립트를 프로젝트 루트에 `restart-server.ps1` 같은 이름으로 저장해 두면, 종료 → 포트 점검 → 재시작을 한 번에 처리할 수 있습니다.

```powershell
param(
    [int]$Port = 3002,
    [string]$Host = '127.0.0.1',
    [string]$Entry = 'server/index.js'
)

$projectRoot = Split-Path -Parent $MyInvocation.MyCommand.Path
Set-Location $projectRoot

$existing = Get-NetTCPConnection -LocalPort $Port -ErrorAction SilentlyContinue | Select-Object -First 1
if ($existing) {
    $procId = $existing.OwningProcess
    Write-Host "기존 서버 프로세스를 종료합니다. PID: $procId"
    Stop-Process -Id $procId -Force
    Start-Sleep -Seconds 1
}

Write-Host ("서버를 재시작합니다. {0}:{1}" -f $Host, $Port)
$env:PORT = [string]$Port
$env:HOST = $Host
node $Entry
```

사용 예:

```powershell
cd D:\Sophia_Check_System
./restart-server.ps1
```

또는 포트/호스트를 직접 바꾸며 실행:

```powershell
./restart-server.ps1 -Port 3002 -Host '127.0.0.1'
```

이 스크립트는 서버가 이미 실행 중이라면 먼저 종료하고, 새 서버를 같은 포트로 다시 띄웁니다. `node server/index.js`를 직접 재실행할 때보다 재시작 과정이 반복적으로 편합니다.

추가로 아래 파일들도 함께 만들었습니다.

- `start-server.ps1`: 서버만 시작
- `stop-server.ps1`: 서버만 종료
- `restart-server.ps1`: 종료 후 바로 재시작

사용 방법:

```powershell
cd D:\Sophia_Check_System
./start-server.ps1
./stop-server.ps1
./restart-server.ps1
```

실행 전, PowerShell 정책이 막혀 있으면 아래를 먼저 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

이후 위 스크립트들을 실행하면 됩니다.
