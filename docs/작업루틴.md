# Sophia-CS 작업 루틴

이 문서는 노트북에서 수정하고, GitHub에 기록하며, 우분투 서버에 반영하고, 실제 브라우저에서 확인하면서 개발을 이어가는 운영 루틴입니다. 매 단계마다 확인을 끝낸 뒤 다음 단계로 넘어갑니다.

## 1. 목표
- 노트북에서 코드 수정
- GitHub에 변경 사항 기록
- 우분투 서버에 반영
- 실제 브라우저에서 확인
- 오류 수정 후 다시 반영
- 기능 단위로 점진적으로 완성

## 2. 작업 환경
- 노트북: Windows + VS Code
- 서버: Ubuntu 서버 (예: 192.168.1.157)
- 프로젝트 경로: /opt/sophia-cs
- 원격 연결: SSH, VS Code Remote-SSH
- 공개 URL: 나중에 Cloudflare Tunnel 연결 후 https://sophiaexp.syntropybooks.com

## 4. SSH 연결 절차
### 4.1 Windows PowerShell에서 연결
```powershell
ssh scp-ubuntu
```

정상적으로 연결되면 아래처럼 프롬프트가 보입니다.
```bash
scipark@ubuntu:~$
```

### 4.2 VS Code에서 원격 연결
- VS Code 실행
- 좌측 하단의 `><` 또는 `SSH` 아이콘 클릭c
- `Remote-SSH: Connect to Host...` 선택
- `scp-ubuntu` 선택
- 연결이 되면 서버 환경의 VS Code 창이 열림

### 4.3 SSH config 예시
Windows의 SSH config 파일 위치는 보통 다음입니다.
```text
C:/Users/user/.ssh/config
```

내용 예시:
```text
Host scp-ubuntu
    HostName 192.168.1.157
    User scipark
    IdentityFile C:/Users/user/.ssh/id_ed25519
    IdentitiesOnly yes
```

확인 명령:
```powershell
Get-Content "$env:USERPROFILE\.ssh\config"
```

## 5. 서버 프로젝트 경로 확인
```bash
ls -la /opt
ls -la /opt/sophia-cs
```

없는 경우:
```bash
sudo mkdir -p /opt/sophia-cs
```

프로젝트가 아직 없으면 GitHub에서 클론:
```bash
cd /opt
sudo git clone https://github.com/secheonio/Sophia-CS.git sophia-cs
```

프로젝트로 들어가기:
```bash
cd /opt/sophia-cs
git status
```

## 6. Git 최신 상태 반영
```bash
cd /opt/sophia-cs
git fetch origin
git checkout main
git pull --ff-only origin main
```

필요하면 브랜치 전환:
```bash
git checkout main
```

확인 기준:
- git status가 clean 상태
- pull이 성공

## 7. 의존성 설치
```bash
cd /opt/sophia-cs
node -v
npm -v
npm ci
```

확인 기준:
- Node/npm 버전 출력됨
- npm ci 성공
- node_modules 생성됨

## 8. 빌드 검증
```bash
cd /opt/sophia-cs
npm run build
```

실패 시 대응:
1. 콘솔의 첫 오류를 읽기
2. 해당 파일 수정
3. 다시 빌드
4. 성공할 때까지 반복

확인 기준:
- 빌드 완료
- dist 폴더 생성
- 오류 없음

## 9. 서버 실행
서버 실행 명령:
```bash
cd /opt/sophia-cs
npm run server
```

또는:
```bash
cd /opt/sophia-cs
node server/index.js
```

확인 기준:
```bash
지출품의 서버:http://127.0.0.1:3001
```
또는
```bash
Server running on http://127.0.0.1:3001
```

중요:
- 서버는 우분투 서버 내부에서 돌아갑니다.
- 브라우저는 노트북에서 확인합니다.

## 10. 브라우저에서 실제 웹 확인
### 10.1 노트북에서 포트 포워딩
PowerShell 또는 VS Code 터미널에서:
```powershell
ssh -L 3001:127.0.0.1:3001 scp-ubuntu
```

이 명령을 실행해 두면:
- 노트북의 127.0.0.1:3001
- 우분투 서버의 127.0.0.1:3001
이 연결됩니다.

### 10.2 브라우저에서 열기
```text
http://127.0.0.1:3001
```

확인 기준:
- 페이지가 뜨는가?
- 로그인 화면 또는 메인 화면이 보이는가?
- 레이아웃이 깨지지 않았는가?
- 버튼과 링크이 동작하는가?
- 오류 메시지가 없는가?
